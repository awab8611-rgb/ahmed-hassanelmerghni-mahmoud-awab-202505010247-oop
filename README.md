## Course Description

BIT1123 introduces object-oriented programming using the Java language. The
lab tutorials progress from setting up a development environment (GitHub and
Codespaces) and writing basic Java programs, through the four core OOP
concepts — encapsulation, inheritance, polymorphism, and abstraction — and
finish with practical topics: collections (ArrayList), file input/output, and
building a graphical user interface with Java Swing.

## How to Run

All projects are plain Java files with no external dependencies. From the
repository root, change into a week folder, compile, and run its main class:

```
cd week2
javac *.java
java Main
```

Entry points per week:

| Week | Folder | Run command |
| ---- | ------ | ----------- |
| 1 | `week1` | `java HelloWorld` or `java StudentGrade` |
| 2 | `week2` | `java Main` |
| 3-4 | `week3-4` | `java Main` |
| 5 | `week5` | `java Main` |
| 6 | `week6` | `java Main` |
| 7 | `week7` | `java Main` |
| 8-9 | `week8-9` | `java Main` (asks for 3 tasks, then saves/loads `task.txt`) |
| 10 | `week10` | `java QuizBattleGUI` (opens a Swing window) |

On a recent JDK you can also run single-file programs directly, e.g.
`java HelloWorld.java`.

## Learning Summary

The tutorials covered the full journey from writing a first Java program to
building a working GUI application. Weeks 1–2 established the environment,
Git workflow, and the basics of classes and objects. Weeks 3–6 built up the
core OOP pillars: inheritance, method overriding, polymorphism, and
encapsulation. Week 7 introduced abstraction with abstract classes, and
Weeks 8–10 applied everything to practical programs using collections, file
I/O, exception handling, and Swing GUI event handling.
